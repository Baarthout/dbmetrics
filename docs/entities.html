entity catalog

Core entities

Every table below is modeled in third normal form with surrogate primary keys to support change data capture. Nullable fields are marked accordingly and all timestamps are UTC.

Table Column Type Description
accounts account_id uuid (PK) Surrogate identifier generated by the platform.
crm_account_key string Immutable key from the upstream CRM vendor.
name string Legal or operating name of the organization.
industry string (nullable) Segment classification aligned to marketing taxonomy.
lifecycle_stage string Prospect, customer, churned, or partner.
annual_revenue numeric(14,2) (nullable) Latest declared annual recurring revenue in USD.
created_at / updated_at timestamp Audit timestamps managed by triggers.
contacts contact_id uuid (PK) Surrogate identifier.
account_id uuid (FK) References accounts.account_id.
full_name string Preferred name for personalized experiences.
email string Primary work email. Unique per contact.
role string (nullable) Job title or persona (e.g., Admin, Champion).
marketing_opt_in boolean True when consent to marketing emails is captured.
opportunities opportunity_id uuid (PK) Unique opportunity record.
account_id uuid (FK) Owning account for the opportunity.
owner_user_id uuid (FK) References users.user_id for the account executive.
stage string Normalized stage (qualification, proposal, closed won).
amount numeric(14,2) Projected ARR in USD.
close_date date (nullable) Expected or actual close date.
order_headers order_id uuid (PK) Primary booking document identifier.
opportunity_id uuid (FK nullable) Links order to its originating opportunity.
order_number string Human-friendly contract number.
status string Draft, pending signature, active, or cancelled.
effective_date date Start date for billing.
total_amount numeric(14,2) Sum of associated order lines.
order_lines order_line_id uuid (PK) Unique line item identifier.
order_id uuid (FK) References order_headers.order_id.
product_id uuid (FK) References products.product_id.
quantity integer Count of units sold.
unit_price numeric(12,2) Price per unit in contract currency.
discount_percent numeric(5,2) (nullable) Percentage discount applied.
supporting dimensions

Lookup & reference tables

Table Column Type Description
products product_id uuid (PK) Catalog identifier.
sku string Stock keeping unit used by finance.
product_family string Grouping used for ARR reporting.
is_retired boolean Marks items removed from active sale.
stages stage_id uuid (PK) Primary key for lifecycle stage.
stage_type string Opportunity, success, or support.
name string Display name presented in CRM UI.
order_rank integer Defines order for funnel visualizations.
users user_id uuid (PK) Internal user identifier.
full_name string Employee name synced from HRIS.
department string Sales, marketing, support, or success.
manager_user_id uuid (FK nullable) Self-referential manager hierarchy.
activity logs

Engagement & support tables

Table Column Type Description
activities activity_id uuid (PK) Unique log identifier.
account_id uuid (FK nullable) Associated account for account-level tasks.
contact_id uuid (FK nullable) Specific contact engaged in the activity.
activity_type string Call, email, meeting, or task.
activity_date timestamp Scheduled or actual activity timestamp.
status string Completed, scheduled, no-show, or cancelled.
activity_outcomes outcome_id uuid (PK) Unique result identifier.
activity_id uuid (FK) References activities.activity_id.
outcome string Result taxonomy (connected, voicemail, etc.).
notes text (nullable) Free-form notes from reps.
support_cases case_id uuid (PK) Support ticket identifier.
account_id uuid (FK) Customer account raising the issue.
priority string Critical, high, medium, or low.
status string Open, waiting on customer, or resolved.
opened_at timestamp Date the ticket was created.
closed_at timestamp (nullable) Resolution date when applicable.
health_snapshots health_snapshot_id uuid (PK) Point-in-time record for customer health.
account_id uuid (FK) Account scored in this snapshot.
score numeric(5,2) Composite health score between 0 and 100.
score_reason text Explanation for automated scoring change.
